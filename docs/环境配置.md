## 2. MySQL

### 2.1 启动

```powershell
Start-Process -FilePath "$env:MYSQL_HOME\bin\mysqld.exe" `
  -ArgumentList '--defaults-file=C:\Users\Zile\dev-tools\my.ini' `
  -WindowStyle Hidden
```

等待几秒后检查：

```powershell
Get-NetTCPConnection -LocalPort 3306 -State Listen
```

### 2.2 连接

```powershell
mysql -u root -p123456
```

数据库名：`fitness_db`。

### 2.3 停止

```powershell
mysqladmin -u root -p123456 shutdown
```

### 2.4 重新导入表结构

`mysql` 客户端对中文路径支持不好，可以先把脚本复制到纯英文路径：

```powershell
Copy-Item .\sql\01_schema.sql C:\Users\Zile\dev-tools\sql\01_schema.sql -Force
Copy-Item .\sql\02_seed.sql C:\Users\Zile\dev-tools\sql\02_seed.sql -Force
mysql -u root -p123456 --default-character-set=utf8mb4 -e "source C:/Users/Zile/dev-tools/sql/01_schema.sql"
mysql -u root -p123456 --default-character-set=utf8mb4 -e "source C:/Users/Zile/dev-tools/sql/02_seed.sql"
```

注意：`01_schema.sql` 会删除并重建业务表，只在需要重置数据时执行。

### 2.5 配置文件

配置文件：`C:\Users\Zile\dev-tools\my.ini`

```ini
[mysqld]
basedir=C:/Users/Zile/dev-tools/mysql-8.0.29-winx64
datadir=C:/Users/Zile/dev-tools/mysql-data
port=3306
character-set-server=utf8mb4
collation-server=utf8mb4_0900_ai_ci
pid-file=C:/Users/Zile/dev-tools/mysql-data/mysqld.pid
log-error=C:/Users/Zile/dev-tools/mysql-data/mysql-error.log
```

如果启动失败，先看 `mysql-data\mysql-error.log`。

## 3. 后端

### 3.1 在 IntelliJ IDEA 中运行

1. 打开 `backend` 目录，等待 Maven 导入完成。
2. 确认 Project SDK 为 JDK 17。
3. 运行 `com.fitness.FitnessApplication`。

### 3.2 命令行运行

```powershell
cd backend
mvn spring-boot:run
```

或者先打包再运行：

```powershell
mvn -DskipTests package
java -jar target\fitness-backend-0.0.1-SNAPSHOT.jar
```

后端地址：`http://localhost:8080/api`

数据库连接默认值：

```text
url: jdbc:mysql://localhost:3306/fitness_db
username: root
password: 123456
```

可以通过环境变量覆盖：`DB_URL`、`DB_USERNAME`、`DB_PASSWORD`、`JWT_SECRET`。

## 4. 前端

```powershell
cd frontend
npm install
npm run dev
```

访问 `http://localhost:5173`。Vite 会把 `/api` 代理到 `http://localhost:8080`。

生产构建：

```powershell
npm run build
```

## 5. 快速验证

```powershell
$body = @{ username = 'demo'; password = 'demo123' } | ConvertTo-Json
$login = Invoke-RestMethod -Uri 'http://127.0.0.1:8080/api/auth/login' `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
$headers = @{ Authorization = "Bearer $($login.data.token)" }
Invoke-RestMethod -Uri 'http://127.0.0.1:8080/api/exercises?page=1&size=5' -Headers $headers
```

## 6. 常见问题

### `java` 或 `mvn` 找不到

关闭当前终端重新打开，让新的用户级 `PATH` 生效。仍然不行时检查：

```powershell
[Environment]::GetEnvironmentVariable('JAVA_HOME', 'User')
[Environment]::GetEnvironmentVariable('Path', 'User')
```

### 后端启动报数据库连接失败

先确认 MySQL 已启动、3306 端口已监听、root 密码为 `123456`，并且 `fitness_db` 已导入。

### 端口被占用

```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen
Get-NetTCPConnection -LocalPort 5173 -State Listen
```

根据 `OwningProcess` 找到进程后再决定是否停止。
